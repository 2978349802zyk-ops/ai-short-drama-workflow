# 头身分拆人设包规范（Seedance 2.5）

> 用途：302 系列三套角色包的建包规范。头部只锁身份，身体只锁造型，两组一起喂，再写绑定句；先验 5 秒短镜再出正片。
> 三套包分开建、互不混用：明版林晚、暗版影、风衣林晚。

---

## 一、通用建包规则（每套包都一样）

### 头部组（只锁身份，不带衣服信息）
1. **定妆头图**：正面、纯色背景、自然表情，脖子以下不入镜
2. **头部三视图**：正面 / 半侧 / 侧面，同一妆发、同一光线
3. 头图禁止出现：衣服、配饰、道具（吊坠属于身体组，头图里不许有）

### 身体组（只锁造型，不带脸）
1. **无头身体三视图**：正面 / 侧面 / 背面，头颈以上裁掉
2. 服装、鞋、配饰、道具全部在身体组里定死
3. 身体组禁止出现：脸、发型

### 绑定句（喂图时写进提示词）
```
人物身份以头部组为准（脸、发型、五官），服装造型以身体组为准（衣服、鞋、配饰、道具），两组是同一个人，不要把身体组的衣服换到别的脸上，也不要改头部的脸。
```

### 验收（先验 5 秒短镜再出正片）
1. 先出 5 秒测试镜：人物站立、转头、走两步
2. 逐项核对：脸对不对、发型对不对、衣服对不对、配饰对不对、道具在哪只手
3. 走样只改那一处重出，不许整包重做
4. 5 秒验收过了才出正片；正片每镜仍带两组图，不许只带一组

### 文件命名
```
<角色名>_头_定妆.png
<角色名>_头_正面.png / <角色名>_头_半侧.png / <角色名>_头_侧面.png
<角色名>_身_正面.png / <角色名>_身_侧面.png / <角色名>_身_背面.png
```

## 二、明版林晚（睡裙线 · 三楼）

### 身份锁死项
- 28 岁，齐肩黑茶色波波头、散刘海，鹅蛋脸，皮肤苍白
- 气质：疲惫但清醒，深夜独自一人

### 造型锁死项（身体组）
- 米白绒面连帽睡裙（帽子戴在头上与否按镜头定，默认不戴）
- 灰色兔子棉拖鞋，兔耳竖起，脚趾脚背裸露，不穿袜子
- 银色小月牙吊坠，细链，位置在锁骨正下方，链子必须可见
- 半满透明杯，**左手拿**（已定人设，全线不许换手，例外必须先确认）

### 绑定句（明版专用）
```
人物身份以头部组为准：28岁，齐肩黑茶色波波头散刘海，鹅蛋脸。服装造型以身体组为准：米白绒面连帽睡裙，灰色兔子棉拖鞋，银色小月牙吊坠在锁骨正下方，左手拿半满透明杯。两组是同一个人，杯子只许在左手。
```

---

## 三、暗版影（睡裙线 · 门内）

### 身份锁死项
- 与林晚长相完全相同（同一个头图基础），区别只在下面三项
- 浅灰色虹膜
- 皮肤过分光滑，像瓷娃娃，表情平静淡漠

### 造型锁死项（身体组）
- 深黑绒面连帽睡裙，黑抽绳
- 赤脚，不穿拖鞋、不穿袜子
- 黑铁小月牙吊坠，黑绳，位置在锁骨正下方
- **双手空着**，不拿任何道具

### 绑定句（影专用）
```
人物身份以头部组为准：与林晚同一张脸，浅灰色虹膜，皮肤过分光滑，表情平静淡漠。服装造型以身体组为准：深黑绒面连帽睡裙黑抽绳，赤脚，黑铁小月牙吊坠黑绳，双手空着。两组是同一个人，不要给她加任何道具。
```

---

## 四、风衣林晚（风衣线 · 四楼）

### 身份锁死项
- 与明版林晚同一张脸（同一头图基础）
- 气质：警觉、克制，深夜走廊独行

### 造型锁死项（身体组）
- 米色风衣
- 双手可攥衣摆（开场镜），无杯子、无吊坠特写要求
- 场景固定：老旧公寓四楼走廊，墙皮剥落，302 门牌，深透视

### 绑定句（风衣版专用）
```
人物身份以头部组为准：与明版林晚同一张脸。服装造型以身体组为准：米色风衣。场景为老旧公寓四楼走廊，冷蓝调。两组是同一个人，不要把睡裙线的衣服和道具带进来。
```

---

## 五、三条线互不混用（红线）

1. 明版林晚、暗版影、风衣林晚三套包的文件分开存，喂图时只许喂当前镜头那一套
2. 睡裙线在三楼，风衣线在四楼，场景不许串
3. 杯子只属于明版林晚的左手；影双手空；风衣版无杯
4. 新镜头提示词和本规范冲突时（比如写了右手拿杯），先停下来确认，不许悄悄改人设
5. 动漫版与写实版分开：本规范默认写实版，动漫版另建包，不许混喂

## 六、验收清单（每镜出片后逐项打勾）

- [ ] 脸和头图一致（五官、发型没漂）
- [ ] 衣服和身体组一致（款式、颜色、抽绳颜色）
- [ ] 吊坠对（明版银色细链 / 影黑铁黑绳），位置在锁骨正下方
- [ ] 鞋对（明版兔子拖鞋 / 影赤脚）
- [ ] 杯子在左手（明版）；影双手空
- [ ] 楼层对（睡裙三楼 / 风衣四楼）
- [ ] 竖屏 9:16，主体在手机安全区内
- [ ] 无后期字幕、水印、台标（场景内 302 门牌、安全出口标识、小广告除外）
