## 通道 D（Muse）—— 2026-11-21 接通

**它和 A/B/C 最大的不同：支持参考图，能把角色的脸和道具锁死。**

用法（`--ref` 可省，传 `--char` 会自动带上该角色的基准图）：

```bash
python manju.py image --provider muse --char linwan --shot S7 \
  --prompt "深夜走廊，林晚后退半步，玻璃杯里的水洒出来" \
  --out "...\04_分镜图产出\S07_muse.png" --yes
```

不加 `--yes` 只预演，不消耗词元。

**必须知道的四个点：**

1. **必须走代理**。muse2api 用真实浏览器（Playwright）打开 muse.ai，直连打不开页面。账号代理已配成 `http://127.0.0.1:7897`（Clash Verge），所以**前提是 Clash Verge 开着**，但**不需要打开"系统代理"开关**。
2. **额度单位是词元（口令），不是积分、不是 neurons**。周额度按百分比算（当前 73%，11月25日重置）；另有 10 亿词元永不过期，已用 0%。
3. **生成慢**。一次出图可能几分钟，超时已设 600 秒（`MUSE2API_IMAGE_TIMEOUT`）。
4. **服务要常驻**。muse2api 不是开机自启，挂了要手动拉：
   ```bash
   cd D:\Hermes环境准备\muse-video-station\upstream\muse2api
   ./.venv/Scripts/python.exe -m uvicorn app:app --host 127.0.0.1 --port 18610
   ```

**自检命令**（不消耗词元）：
```bash
# 服务活着没
curl -s --noproxy "*" http://127.0.0.1:18610/healthz
# 代理出口 + 会话（需要 key，见 .env）
curl -s --noproxy "*" -X POST http://127.0.0.1:18610/admin/accounts/87882bcd070d/proxy/test \
  -H "Authorization: Bearer <key>" -H "Content-Type: application/json" \
  -d '{"proxy":{"server":"http://127.0.0.1:7897"}}'
```
