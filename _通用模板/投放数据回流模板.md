# 投放数据回流模板

> 用途：每次投放后把数据记下来，写回剧本模板的约束，让下一集自动变好。
> 位置：放进每部剧的 `09_复盘与数据\`，一集一行，投了再填。
> 原则：没有数据的复盘是感觉，有数据的复盘才是回流。

---

## 一、每集必记的 6 个数

| 指标 | 记什么 | 为什么记 |
|---|---|---|
| 3 秒留存率 | 前 3 秒没划走的比例 | 钩子成没成，第一镜的命 |
| 完播率 | 看完整集的比例 | 节奏和反转密度成没成 |
| 平均观看时长 | 秒 | 和集长比，知道掉在哪一段 |
| 划走点 | 划走最集中的秒数（平台后台有曲线） | 哪一镜把人赶走了 |
| 互动率 | 点赞+评论+转发 / 播放 | 内容有没有"想说一句"的点 |
| 转粉率 | 新增关注 / 播放 | 断点结尾成没成，想不想看下一集 |

## 三、达标线（低于线 = 下集必须改对应环节）

| 指标 | 达标线 | 低于线改什么 |
|---|---|---|
| 3 秒留存 | ≥ 60% | 第一镜钩子重做：异常信息提前、第一镜再短 |
| 完播率 | ≥ 30% | 节奏：砍推进镜、反转加密、平均镜长压到 2.5s 内 |
| 划走点 | 不集中在同一镜 | 那一镜重剪或删，查它的 `hook_info` 是不是空的 |
| 转粉率 | ≥ 0.5% | 结尾断点不够狠：断点再往前挪，停在更想看下去的帧 |
| 互动率 | ≥ 3% | 内容缺争议点/共鸣点，下集加一句能引评论的台词或画面 |

> 达标线是起步值，投 3 集之后按自己的数据中位数调整，不要一直用别人的线。

## 四、回流规则（数据 → 改哪里）

1. **3 秒留存低** → 改钩子结构模板的约束块：第一镜时长上限从 2.5s 压到 2s，异常信息必须在第 1 镜出现（不许第 2 镜才出现）。
2. **划走点集中在某一镜** → 查那一镜的 `function` 和 `hook_info`：推进镜无新信息就删，反转镜不够狠就换反转点。
3. **完播率低但 3 秒留存高** → 钩子没问题，问题在中段：反转密度从"每 15 秒 1 个"加密到"每 10 秒 1 个"。
4. **转粉率低但完播率高** → 内容看完了但不想追：结尾断点往前挪 3–5 秒，停在答案揭晓之前。
5. **互动率高** → 记下是哪一镜/哪句台词引的评论，下集同位置再放一个同类点。

每次回流只改一条规则，改完在下面登记，避免多变量一起动不知道谁起的作用。

## 七、复盘动作清单（每集投完 24 小时内做完）

1. 把 6 个数填进第二节记录表
2. 对第三节达标线，标出哪条没达标
3. 按第四节回流规则，只改一条规则
4. 在第五节登记改了什么
5. 下一集生成时把改后的约束带进剧本 prompt
6. 下一集投完后回填第五节的"下集验证结果"
