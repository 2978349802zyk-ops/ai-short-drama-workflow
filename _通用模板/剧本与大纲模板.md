# 剧本与大纲模板（写实版）

> 本项目专用模板。新一集照这个填，风格一律写实电影质感。

## 一句话故事

一句话讲清"谁 + 遇到什么 + 结果"，不要写"然后呢"。

例：独居女子深夜回家，发现门后住着一个和她一模一样的自己。

## 人物卡

按 `01_创意与剧本/人物设定.md` 的外观锁填，**逐字复制，不缩写**：

```
林晚：齐肩黑茶色碎发，额前散落几缕碎刘海，鹅蛋脸，皮肤偏白，穿米白色加绒连帽睡裙，光脚踩浅灰色兔子造型棉拖，脖子上挂着一枚银质小月牙吊坠，左手常握一只半满的透明玻璃杯
```

## 分场剧本格式

```
### 场景一：<场景名>

**地点**：具体到门牌号（如：回声公寓 3 楼 302 门前）
**出场**：角色名

<一段画面描述，写清光线、声音、人物在做什么>

**台词**
- 角色：「台词内容」
```

## 台词规则

| 项 | 规则 |
|---|---|
| 语速 | 每秒 4.5 字（中文正常语速） |
| 单镜台词 | ≤ 25 字（10 秒镜头） |
| 旁白 | 尽量不用。本剧走"现场声 + 人物台词"，不用旁白交代 |
| 影的台词 | 必须与林晚台词完全相同，标注"（与林晚完全相同的音色，延迟两秒）" |

## 镜头数规划

| 集长 | 镜头数 | 单镜时长 |
|---|---|---|
| 2.5 分钟 | 15 镜 | 10 秒 |
| 1.5 分钟（省积分档） | 15 镜 | 6 秒 |

**镜头越少越省积分。** 能用一个镜头讲清的，不要拆成三个。

## 禁止

- 不用旁白交代剧情（观众要自己看懂）
- 不写"镜头拉远展现全景"这类概括描述
- 人物外貌不缩写
