## 五、视频提示词写法

视频提示词**只写动作和运镜，不写风格词**（风格已由首帧图确定）。

格式：

```
[首帧状态] + [主体动作，一句一个动作] + [运镜方式] + [环境反应]
```

示例（S09 镜像抬手）：

```
门外的手缓缓抬起，门缝内的手以完全相同的轨迹同步抬起，两只手在门缝两侧镜像对称，运镜平稳，画面稳定，无文字无水印
```

**必须遵守**：

- 动作分句写，一句一个动作，AI 才跟得上
- 只写一个主体的主动作，多人同框写清"谁做什么"
- 结尾固定带 `运镜平稳，画面稳定，无文字无水印`
- **不写**"镜头拉远展现整个房间"这类概括描述，AI 会乱切

## ⚠️ 小物件成像标准（2026-11-21 实测后新增，硬性）

### 一句话

**提示词写得再全也没用。小物件能不能画出来，取决于它在画面里占多少像素。**

### 实测证据

| 项目 | 数据 |
|---|---|
| 出图 | `S07_muse.png` 498×885 全身 |
| 脖子区域高度 | 仅 **70–90 像素** |
| 月牙吊坠推算宽度 | **10–15 像素** |
| 结果 | 皮肤是光的，吊坠完全没画出来 |

提示词里吊坠已经前置、重复、不缩写，**依然漏**。说明这不是措辞问题。

### 硬性规则

1. **小物件（吊坠 / 戒指 / 耳饰 / 眼镜 / 手表）在成图里必须占 ≥ 30 像素**，低于此必然丢失。
2. **构图限制**：要保住锁骨吊坠，镜头**最远到七分身（膝上）**，且锁骨区域必须清晰可见、不被衣物遮挡。
3. **全身 / 全景镜头：不指望模型画出吊坠。** 这类镜头出图后必须用 IOPaint 局部补，或直接接受"远景看不到小物件"的物理现实。
4. **基准图必须是半身或七分身**，不能是全身。基准图是模板，模板里没有的东西，参考图机制会连"没有"一起锁进去。
5. 已证伪的方案（不要再试）：把吊坠写进提示词开头、重复三次、加"必须出现"、加括号强调 —— **全部无效**。

### 验收方法（每张图必做）

出图后放大脖子区域自检，**肉眼能看见链子 + 坠子才算过**。只有"锁骨处有个亮点"不算。

> 教训：2026-11-21 曾把衣服上的金属抽绳圆环误判成吊坠，报"吊坠 ✅"。确认时必须看清"细链 + 下垂的月牙"，两者缺一即判不合格。
