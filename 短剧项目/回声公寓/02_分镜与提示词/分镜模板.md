# 分镜模板（写实版）

> 分镜表字段定义与填写规范。实际 15 镜见 `分镜表.csv`。

## 字段定义（15 列）

| 字段 | 含义 | 填写要求 |
|---|---|---|
| 镜头编号 | 两级制 EP01_P01_S1 | 集_段_镜 |
| 镜头标题 | 4 字概括 | 如"死寂楼道" |
| 场景 | 拍摄地点 | 具体到门牌号 |
| 出场人物 | 出场角色 | 多人用逗号分隔，无则写"无" |
| 画面描述 | 剧情目的 | 这一镜要让观众看到/明白什么 |
| 人物动作 | 动作定格 | 只写一个关键动作 |
| 台对白 | 台词 | 无对白写"无" |
| 景别 | 全景/中景/中近景/近景/特写/大特写 | 与机位配套 |
| 运镜方式 | 固定/缓慢推进/下摇/手持轻晃/快速推近 | 单镜只用一种 |
| 图片提示词 | 出图用完整提示词 | 风格锁 + 场景 + 人物锁 + 动作 + 景别 + 光线 + 画幅 |
| 视频提示词 | 动作描述 | **只写动作和运镜，不写风格词** |
| 负面提示词 | 排除项 | 无文字/水印/畸形手/多余人物 |
| 声音设计 | 环境音与音效 | 写清"只有什么声音" |
| 时长 | 秒 | 默认 10（省积分档可降到 6） |
| 审核状态 | 待重制/已定稿 | 定稿才进入出图 |

## 时长规则

- 本项目单镜 **10 秒**（Muse 版基线），省积分档可降到 6 秒
- 15 镜 × 10 秒 = 150 秒 ≈ 2.5 分钟
- 台词按每秒 4.5 字算，10 秒镜头最多 25 字

## 一致性检查（每镜必对）

- [ ] 风格锁逐字一致
- [ ] 人物外观锁一字不改
- [ ] 场景描述用锁定原文
- [ ] 负面提示词带了
- [ ] 画幅 9:16 竖屏

## 画面安全区

9:16 竖屏，主体集中在画面中部，避开底部字幕区（下方 15%）和顶部状态栏（上方 8%）。

## 出图顺序

1. 先出**两张角色图**（林晚、影），互相对得上同一张脸
2. 再出**场景图**（楼道、门口、玄关）
3. 最后按镜头出**分镜图**，每张都以角色图/场景图为参考
