判定规则（当前）

层检查通过条件失败后果
技术分辨率 / 画幅 / 时长 / 编码竖屏 9:16，1–15 秒，可解码直接不合格
语义每条 must 断言任一帧判 yes全帧 no → 不合格
语义must_not 断言不出现违规项出现 no → 不合格
语义断言与提示词不同步降级处理只记部分通过，不误伤
汇总全通过 / 部分 / 不合格有不合格→FAIL；否则有部分→PARTIALFAIL 触发重写重试

实测证据（历史素材，没生成新片）

FAIL 走廊灯灭 vs 公仔视频
  • 画幅 480×480 方形，不是竖屏
  • 画面无走廊、无可天花板顶灯
  • 实际是玩偶特写，无纵深推进
  • 画面白亮，与「灯熄灭」相反
→ 逐条抓出，用户说的问题可自动检出
PARTIAL 敲门视频 vs 敲门断言
  • 竖屏 / 冷蓝色调 / 手贴门板 → 通过
  • 门牌 302 不再误判成水印
  • 模型自己加的「袖口」「光带」没出现 → 只记部分
→ 不因过度要求误伤成硬失败
边界：抽帧证明不了「一盏接一盏」的时间顺序。真要递进动作必须拆多镜——框架只在提示词阶段警告，还没做自动拆镜。
