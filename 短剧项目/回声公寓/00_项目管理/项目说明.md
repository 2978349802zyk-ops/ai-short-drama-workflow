# 项目说明

## 目录用途与禁忌
| 目录 | 放什么 | 不要放什么 |
|---|---|---|
| 01_创意与剧本 | 大纲/人物/剧本定稿 | 提示词 |
| 02_分镜与提示词 | 分镜表/提示词 | 图片/视频文件 |
| 03_角色与场景素材 | 角色定妆图/场景图 | 成片 |
| 04_视频镜头 | 生成的镜头片段 | 配音 |
| 05_配音与音效 | wav/mp3 配音与BGM | 视频 |
| 06_剪辑工程 | 拼接清单/中间文件 | 最终交付件 |
| 07_最终成片 | 交付用 mp4 | 中间产物 |
| 08_复盘与数据 | 复盘/统计 | 素材 |

## 命名规范
- 镜头图：`S<镜号>_<简称>.png`，如 `S01_夜楼道.png`
- 配音：`V<镜号>_<角色>.mp3`
- 成片：`回声公寓_EP01_样片_v01.mp4`

## 约定
- 不写任何密钥、token、密码、连接串到本项目。
- 最小试制：先做 6 镜约 24 秒验证链路，跑通再扩。

## 待确认信息
- 画风：默认沿用 V1.0 长期规范（国产动画厚涂 / 冷蓝暗调 / 9:16）；用户未改则不动。
- 视频大模型：环境未配置，样片用「图 + ffmpeg 运镜」替代，muse.ai 接入暂留空。
