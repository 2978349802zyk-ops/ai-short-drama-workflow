# 配音模型实测记录

> 环境：RTX 5060 8GB · torch 2.8.0+cu128 · CUDA 12.8 · Speech-AI-Forge API (127.0.0.1:7870)
> 测试文本：「深夜的走廊里，只有我一个人的脚步声。」（19 字）

## 一、CosyVoice2-0.5B（可用）

| 项目 | CPU（torch 2.6） | GPU（torch 2.8+cu128） |
|---|---|---|
| 首次（含加载） | 47 秒 | 14.6 秒 |
| 后续短句 | 17.5 秒 | — |
| 26 字长句 | — | **7.7 秒** |
| 输出 | 88 KB WAV | 同 |
| 音色 | 仅 `mona`（唯一带参考音频的内置音色） | 同 |

**结论：GPU 下 7.7 秒/句，稳定可用。一集 15 镜约 2 分钟。**

踩过的坑：
- `CosyVoiceModel.py` 缺 `import soundfile as sf` → 已补
- `female2` 等音色直接报 "must be generated using reference audio"（zero-shot 必须有参考音频）
- torch 2.6 在 Blackwell(sm_120) 上无内核 → `CUDA error: no kernel image is available`

## 二、qwen3-tts-17cv（Qwen3-TTS-12Hz-1.7B-CustomVoice，不可用）

| 项目 | 实测值 |
|---|---|
| 模型大小 | 4.3 GB（3.57 GB 主权重 + 其它） |
| 下载 | ModelScope 镜像，688 MB/分钟，约 6 分钟 |
| 内置音色 | **9 个**（Vivian/Serena/Uncle_Fu/Dylan/Eric/Ryan/Aiden/Ono_Anna/Sohee） |
| 显存占用 | 6042–7475 MB（8 GB 卡几乎占满） |
| GPU 利用率 | 仅 22%（在等显存换页） |
| **生成 19 字耗时** | **587 秒（9.8 分钟）** |
| **输出时长** | **230.8 秒（3 分 51 秒）—— 严重跑飞** |
| 能量分布 | 第 1 段(0-10s) RMS 1732 有声；第 2-23 段 RMS 25-217 全程静音 |

## 三、接入要点（SAF API）

- 正确端点：`POST /v2/tts`（`/v1/audio/speech*` 不存在）
- 请求体：
```json
{"text":"...","tts":{"mid":"cosy-voice-2"},
 "spk":{"from_spk_name":"mona"},
 "infer":{"seed":42,"sync_gen":true,"timeout":900}}
```
- `spk.from_spk_name` 必须能在 `data/speakers/*.spkv1.json` 里找到，否则 `seg.spk` 为 None 报 `'NoneType' object has no attribute 'name'`
- 新增内置音色：复制 `female2.spkv1.json` 结构，改 `name`/`desc`/`gender`/`id`，`token` 留空数组
- `refs` 字段是 **base64 内嵌音频**，不是文件路径
- 启动自动下载模型：`export auto_download='qwen3*'` 后启动 `launch.py`
- 返回的 WAV 头可能没回填（`wave` 读到 0 帧），用 ffprobe 或 ffmpeg 重封装读真实时长

## 四、选型结论

| 方案 | 状态 | 适用 |
|---|---|---|
| CosyVoice2 GPU | ✅ 已验证 | 主力，7.7 秒/句 |
| qwen3-tts 0.6B GPU | 未测（约 1.2 GB，显存友好） | 音色库候选 |
| qwen3-tts 1.7B | ❌ 显存不足跑飞 | 需 ≥12 GB 显存 |

## 五、第一集全链路配音实测（2026-11-21，CosyVoice2 + mona）

### 7 段台词

| 镜号 | 台词 | 音频时长 | 生成耗时 | 输出 |
|---|---|---|---|---|
| S2 | ……几点了，怎么一点声音都没有。 | 3.96 s | 14.8 s（含加载） | 190 KB |
| S3 | ……302，这光是从门缝里透出来的？ | 6.88 s | 7.9 s | 322 KB |
| S4 | ……谁？ | 2.52 s | 3.9 s | 118 KB |
| S5（影） | ……谁？ | 2.52 s | **0.3 s**（缓存） | 118 KB |
| S10（林晚） | 你是谁？ | 2.32 s | 3.8 s | 108 KB |
| S10（影） | 你是谁？ | 2.32 s | **0.2 s**（缓存） | 108 KB |
| S11 | 你到底想干什么！你到底是谁！ | 4.20 s | 5.1 s | 196 KB |

**合计音频 24.7 秒，总生成耗时约 36 秒（7 句）。**

### 关键发现

1. **服务端有缓存**：相同 `text + spk + seed` 第二次请求直接返回，耗时 0.2-0.3 秒，输出字节完全一致（S4/S5 都是 121004 字节，S10 两句都是 111404 字节）。
2. **对本剧的用处**：影的台词本就是林晚的复制，同音色同文本 → **影的所有台词几乎零成本**。
3. **"延迟两秒"必须后期做**：TTS 输出的是同一段音频，时间差要在剪辑轨道上错开。
4. **语速参考**：中文约 4-5 字/秒。S3 的 18 字出 6.88 秒偏慢（应 5-6 秒），可用 `atempo=1.10~1.15` 校正。
