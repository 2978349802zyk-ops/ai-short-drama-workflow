## 一、五条结论

1. **林晚 = Serena（qwen3-tts-06cv）**，speed_rate **0.92–0.95**，temperature **0.50–0.55**。不用再下别的模型。
2. **影 = 不另选音色**，直接复用林晚同一条 wav（同一文件、同一 MD5）+ 门内滤波 +（S10）延迟 2s。台词表要求"完全一致"，用同一文件是唯一能做到 100% 一致的方案；差异感交给声场（低通 3 kHz + 短反射）而不是音色。
3. **S11 用「temperature 0.70 + speed 0.88 + 压缩/EQ/限幅」单条生成**。instruct/prompt1 三条链路实测全部失效，别再试；temperature 是唯一有效且可复现的情绪旋钮。
4. **继续全片配（7 段）**。生成成本约 1 分钟，全部台词时长都落在镜头容量内（最长 4.67 s vs 镜头 5–10 s），客观指标已进入自然人声区间，唯一高风险句 S11 已有可执行处理。
5. 7 条 wav + 23 s 预览已产出，敏儿可直接上轨（见第八节）。

判据：
- 成年女声自然 F0 中位约 180–250 Hz。mona 全线 **318–387 Hz** 越界；「谁？」跨度只有 **2.4 st**、帧间抖动 0.2 st → 音高几乎不动，这是"太人机"最硬的客观证据；且 2 个字拉 2.52 s（0.79 字/s），拖长且平。
- mona S03 18 字用了 6.88 s（2.62 字/s），句内只有 1 处停顿 → 典型匀速念稿。
- Serena 三条长句 F0 235–271 Hz、跨度 9.7–10.3 st、语速 3.85–4.45 字/s，全部落在自然人声区间；F0 跨度比 mona 大 30–50%，这就是"有起伏"的可测来源。
- **别再降 speed**：低于 0.90 会把 4.5 字/s 拖到 3.5 以下，直接回到 mona 的念稿速度。

## 三、instruct 判定（已闭环，勿再投入）

同文本 / 同 seed=42 / 同 speed，只改情绪提示，输出 **MD5 完全相同**：

| 链路 | 请求 | 结果 |
|---|---|---|
| `/v2/tts` `tts.prompt1` | 无 / "压低声音气声恐惧" / "愤怒大喊崩溃" | `eefca835…` ×3 **全同** |
| `/v1/tts?prompt1=` | 同上两版 | **全同** |
| SSML `<s prompt1="…">` | 有 / 无 | `038b61a5…` ×2 **全同** |

→ 0.6B CustomVoice 的 instruct 在当前 SAF 版本是死路（源码里 instructs 取自 `seg.prompt1`，但 API 层没有入口）。
→ **有效旋钮是 temperature**（实测、可复现）：S11 从 T0.55→T0.70，F0 中位 **245.2 → 294.9 Hz**（+4.0 st），RMS **−18.6 → −16.7 dB**；同参数重跑 MD5 一致，说明不是随机噪声。

## 五、S11「你到底想干什么！你到底是谁！」可执行方案

**采用：单条 T0.70 / speed 0.88 + 后处理**（已生成并测过，成品 `S11_林晚_崩溃.wav`）

```bash
ffmpeg -y -i S11_raw.wav -af "acompressor=threshold=-18dB:ratio=3.5:attack=6:release=90,\
equalizer=f=1200:t=q:w=1.2:g=2.5,alimiter=limit=0.95,loudnorm=I=-15:TP=-1.5:LRA=11" \
-ar 24000 -ac 1 S11_林晚_崩溃.wav
```
测量结果：F0 中位 289 Hz、跨度 10.6 st、RMS −15.7 dB（全片最响）、峰值 −1.5 dB。对比 mona 同句（359 Hz / 6.8 st / −14.8 dB）：Serena 音高更低但**动态范围大 55%**，喊叫感来自起伏和响度，不靠把音高顶上去。

**弃用方案（已实测，别再走）**：拆句生成（"你到底想干什么！"+"你到底是谁！"+0.30 s 换气）→ 后半句 F0 掉到 **205 Hz**、跨度 1.9 st，情绪反而塌了，整体 −23 dB，比单条差。
**备选（只在敏儿听后判定"还不够喊"时启用）**：IndexTTS2 零样本克隆（timbre ref = Serena S02，emotion ref = 一段中文喊叫参考音频），需从 ModelScope 下 ~2.5 GB，约 4 分钟；本地 `models/Index-TTS-2` 目前是空目录，未下载。触发条件写死：敏儿 A/B 后认为 S11 明显弱于其他句，才做，否则不动。

## 六、混音参数（给敏儿）

- 对白基准 **−18 LUFS**（RMS −18～−21 dBFS），峰值 ≤ −1.5 dBFS。
- 影：比同句林晚 **低 3 dB**（当前 −21 LUFS），门内滤波链：`lowpass=f=3000,highpass=f=120,aecho=0.8:0.55:17|29:0.22|0.13`。
- S11 单独抬到 −15 LUFS，拍门声在其后 0.15 s 进入，避免盖住"你到底是谁"的尾字。
- S02/S03/S04 是"夜里不敢出声"，混音时再压 2–3 dB + 加台词表里那几层环境声（棉拖、玻璃杯、呼吸），不要靠 TTS 出气声——模型做不到气声，别指望。
- S10 影的 2 s 延迟已烘进文件（`S10_影_你是谁_延迟2s.wav`），对齐时直接放在林晚那句起点的 +2.0 s。
