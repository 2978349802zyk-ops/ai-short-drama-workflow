## 1. 校验口径：8 条主校验 + 1 条分类纪律

> 固定口径：**主校验 8 条，第 9 条分类纪律单列**，不合并进第 8 条、不放宽、不降级为「建议项」。任一条不过即记不合格（试跑长度豁免见第 0 节）。

### 1.1 主校验 8 条（逐条）

| # | 校验项 | 判定标准 | 判定方式 | 自动/语义 |
|---|---|---|---|---|
| ① | 第一镜钩子 | 第 1 镜 `function` == `钩子` | 精确值比对 | 脚本算（取字段）+ 语义判（钩子含义由 cc-review 复核） |
| ② | 前 3 秒异常信息 | 前 3 秒镜的 `hook_info` 非空，且含异常/悬念信息（不该出现的东西、反常动作、悬念画面） | 非空由脚本算；「含异常/悬念」语义判 | 混合 |
| ③ | 首次反转位置 | 第 3–5 镜内至少一个 `function` == `反转` | 定位 3–5 镜并查值 | 脚本算（定位/计数）+ 语义判（反转是否成立） |
| ④ | 反转密度 | 全集 `反转` 镜数量 ≥ 全集总时长(秒) / 15（即 ≥ 每 15 秒 1 个）；短集照算并记数 | 数值计算 | 脚本算 + 语义判（反转是否真为反转） |
| ⑤ | 推进连续性 | `function` == `推进` 的镜连续不超过 2 镜；第 3 镜连续推进即不合格 | 扫描最长连续段 | 脚本算 + 语义判（推进/反转边界） |
| ⑥ | 断点结尾 | 最后一镜 `function` == `断点`，且无解释性台词/旁白（不收尾、不解释、不总结） | 末镜值比对；台词/旁白文本语义判 | 脚本算（末镜字段）+ 语义判（解释性文本） |
| ⑦ | 逐镜 hook_info | 每镜 `hook_info` 非空（写不出即应删镜） | 逐镜非空检查 | 脚本算 |
| ⑧ | 平均镜长 | 全集平均镜长 ≤ 2.5s；计算式 = 各镜时长之和 ÷ 镜数，逐镜时长从数据读取 | 数值计算 | 脚本算 |

### 1.2 分类纪律第 9 条（单列，不放宽）

| 子项 | 判定标准 | 判定方式 |
|---|---|---|
| 9a | `function` 只能四选一：`钩子` / `推进` / `反转` / `断点`；出现第五类值（如「悬疑留白」）**直接不合格**，不并入推进、不改名放行 | 脚本算（枚举值检查）+ 语义判（cc-review 复核归类） |
| 9b | `suspense_pause` 是节奏标签，**不是 function**；带该标签的镜其 `function` 仍为四选一，且只能是 `推进`/`反转`/`断点`（不许标 `钩子`） | 脚本算（字段组合检查）+ 语义判 |
| 9c | 带 `suspense_pause: true` 的镜：**全集 ≤ 2 镜**、**只许放在反转之后**、**时长 ≤ 4s**、**`gen_mode` 固定 `still`** | 脚本算（计数/时长/gen_mode/位置）+ 语义判（「反转之后」的时序） |

> 第 9 条独立于 1–8 条：不得因为它「只是标签」而豁免，也不得以 1–8 条全过为由跳过 9a/9b/9c。

## 2. 脚本算 / 语义判 分工（唯一同步口径）

### 2.1 脚本算（cc-python 负责，输出可复核的结构化结果）

| 项 | 输入 | 计算/检查规则 | 输出要求 |
|---|---|---|---|
| JSON 语法 | `剧本.json` | 能被标准 JSON 解析，无语法错 | 解析成功/失败 + 错误位置 |
| 字段齐全率 | 每镜 | 必含 `function`、`hook_info`、时长字段（字段名以实际数据为准，缺失需标注）；`suspense_pause` 可缺省 | 逐镜缺失清单 + 齐全率百分比 |
| 镜数 | 剧本 | 统计总镜数 | 数字（EP02 预期 7） |
| 逐镜时长 | 剧本 | 逐镜读取时长 | 数组 [t1, t2, ...] + 总和 |
| 平均镜长 | 由上两项 | Σ时长 ÷ 镜数 | 数值 + 与 2.5s 的差值 |
| ①① 等取值类 | 每镜 `function` | 精确值比对：首镜=`钩子`、末镜=`断点`、3–5 镜含 `反转`、最长连续 `推进` 段、各镜 `function` 枚举合法性 | 逐镜取值表 + 命中/未命中 |
| ②⑦ `hook_info` 非空 | 每镜 | 去空白后长度 > 0 | 逐镜布尔 + 为空镜号 |
| ④ 反转计数/密度 | 每镜 `function` + 时长 | 反转镜数、密度 = 反转数 ÷ 总时长（每 15 秒个数 = 密度 × 15） | 数值 |
| 9a/9b/9c 可机检部分 | `function`、`suspense_pause`、`gen_mode`、时长、镜序 | 第五类值检测；标签镜的 function 合法范围；总数 ≤2；时长 ≤4s；gen_mode == still；标签镜前一镜存在 `反转`（位置关系粗判） | 违规清单 |

**脚本只给事实与可机检违规，不给终审结论。** 输出文件：`校验数据_EP02.json`。

### 2.2 语义判（cc-review 负责，逐条引用脚本事实）

| 项 | 判定内容 | 判定要点 |
|---|---|---|
| ② | 前 3 秒 `hook_info` 是否真含异常/悬念，而非普通描述 | 只写「主角站着」不算；「门里有人在看」「不该出现的东西」算 |
| ③ | 3–5 镜的 `反转` 是否推翻预期或异常升级 | 只是切镜/移动不算反转 |
| ④ | 被计为 `反转` 的镜是否名副其实（影响密度真实性） | 机检计数以语义复核为准 |
| ⑤ | 连续推进被打断处是否真为新信息/反转 | 避免为过检硬标反转 |
| ⑥ | 末镜台词/旁白是否解释性（收尾、总结、说明） | 有解释性旁白即第 6 条不过 |
| 9a | 第五类值的实际叙事归类 | 「悬疑留白」等按叙事作用重新归入四选一，但不免除「出现第五类即不合格」的记录 |
| 9b/9c | `suspense_pause` 镜是否确在反转之后、是否确为留白而非偷换 function | 时序与标签性质复核 |

语义判只针对上述 8+1 条，不扩展到画风、配音、镜头美感等无关维度。输出文件：`校验复核_EP02.md`。
