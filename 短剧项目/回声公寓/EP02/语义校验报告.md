## 1. 主校验 8 条

### ① 第一镜 function == 钩子 —— **通过**

- 镜号：EP02_P01_S1
- 证据：`剧本.json` S1 `"function": "钩子"`（分镜表 CSV 同值）；`hook_info`: 「深夜门外有敲门声，观众和主角同时听到但看不见人」。
- 语义复核：S1 无背景交代、无铺垫，直接给异常（深夜敲门但看不见人），验收标准自述「观众前2秒听到敲门声并看到主角警觉，无背景交代，钩子成立」，与模板第一节钩子段定义吻合。

### ② 前 3 秒异常信息（hook_info 非空且含异常/悬念）—— **通过**

- 范围判定：前 3 秒 = S1（2s）+ S2（2.5s）累计至 4.5s，覆盖镜为 S1、S2（蓝图第 6 节第 2 条口径：按累计时长 ≤3s 覆盖的镜记录；S1 2s < 3s，S2 使累计越过 3s，两镜均在前 3 秒窗口内起作用）。
- 镜号：EP02_P01_S1、EP02_P01_S2
- 证据：S1 `hook_info` =「深夜门外有敲门声，观众和主角同时听到但看不见人」；S2 `hook_info` =「门外走廊空无一人，敲门声却没有停」。
- 语义复核：两镜 hook_info 均非普通场景描述——「听到敲门却看不见人」「门外无人但敲门声不停」均属反常事件/悬念画面（不该出现的东西+反常现象），非「主角站着」类中性描述。
- 观察项：S1+S2 累计 4.5s，超过「前 3 秒」窗口本身（第一镜 2s 单独在 3s 内，异常在 0–2s 已成立，故不构成不合格）。

### ③ 第 3–5 镜内至少一个反转 —— **通过**

- 镜号：EP02_P01_S3（反转）、EP02_P01_S5（反转）
- 证据：`剧本.json` S3 `"function": "反转"`、S5 `"function": "反转"`（CSV 同值）。
- 语义复核：
  - S3「监控画面里走廊空无一人，但灯一盏盏自己亮」——主观猫眼视角切客观监控，「不是她看错」预期被证实且异常升级，属真反转，非切镜/移动。
  - S5「观众得知那扇门三年没人住，敲门对象本身就是异常的」——揭示敲门对象是空置三年房间，推翻「敲门针对住户」的默认预期，属真反转。
  - S4 标「推进」（拨电话、恐惧蔓延到人），语义上确实是信息交代而非反转，边界清晰，无「为过检硬标反转」迹象。

### ④ 反转密度 ≥ 每 15 秒 1 个 —— **通过**（附短集观察项）

- 卡2 确定性输入：总时长 17s（`确定性检查报告.md` 第 4 节）。
- 语义复核计数：全集反转镜 = S3、S5、S6 共 **3 个**（S6 标「反转」且带 suspense_pause 标签，function 本身仍为反转，计数时按 function 字段计）。
- 计算：3 个 ÷ 17s × 15s = **每 15 秒 2.65 个** ≥ 1，达标。
- 语义复核：S3、S5 已在③确认为真反转；S6「一排灯在无人情况下依次亮起，从走廊深处烧向302」为异常升级（灯潮逼近目标门），符合「异常升级一次」定义，名副其实。
- 观察项（短集豁免，不作不合格依据）：17 秒试跑集对「每 15 秒 1 个」阈值天然占优，该密度数值仅在完整集规格下才有节奏意义；照蓝图第 0 节记观察项。

### ⑤ 推进不连续超过 2 镜 —— **通过**

- 证据：全集 function 序列 = 钩子(S1) / 推进(S2) / 反转(S3) / 推进(S4) / 反转(S5) / 反转(S6) / 断点(S7)。

- 语义复核：S2（猫眼确认无人）与 S4（打电话求证）各自独立交代新信息，与相邻反转边界真实，不存在为打断推进而硬塞反转。

### ⑥ 最后一镜 function == 断点且无解释性台词/旁白 —— **通过**

- 镜号：EP02_P01_S7
- 证据：`剧本.json` S7 `"function": "断点"`（CSV 同值）；`"dialogue": "无"`；台词表中无 S7 条目（台词表仅含 S2/S4/S5 三镜）。

## 2. 分类纪律第 9 条（单列，不并入 1–8 条）

- 证据：7 镜 function 实测序列 = 钩子 / 推进 / 反转 / 推进 / 反转 / 反转 / 断点。

- 语义复核：各值与叙事作用一致（见①③⑤⑥逐镜复核），无改名放行痕迹。

### 9b suspense_pause 是标签非 function，带标签镜 function 不为钩子 —— **通过**

- 证据：全集带 `suspense_pause: true` 的镜仅 **1 镜** = EP02_P01_S6，其 `"function": "反转"`（剧本.json S6 字段与 CSV function 列均如此；「悬疑留白」出现在「剧情目的」字段，即叙事描述，未污染 function）。
- 判定：标签与 function 正确分离；S6 function = 反转 ∈ {推进/反转/断点} 合法范围，非钩子。

### 9c 带 suspense_pause 标签的镜 ≤2、只在反转之后、时长 ≤4s、gen_mode == still —— **通过**

- 数量：标签镜 1 镜 ≤ 2，达标（EP02_P01_S6）。
- 位置（「反转之后」）：S6 自身 function = 反转；前一镜 S5 为反转，再前一镜 S4 为推进。蓝图第 6 节第 3 条「标签镜前一镜存在反转（位置关系粗判）」——S5 是反转，粗判通过；语义复核：S6 内容「灯潮逼近302门前、压迫感顶点、死寂两秒」承接 S3/S5 反转后的留白，属反转后蓄力，非偷换 function，时序判定通过。边界说明：S6 自身即为反转镜（反转同镜带标签的情形），按蓝图「恰在反转同镜带标签记待确认」之约定，本卡记录为：S6 前一镜 S5 确为反转，位置条件成立，**不构成违规**。
- 时长：S6 建议时长 2.5s ≤ 4s，达标。
