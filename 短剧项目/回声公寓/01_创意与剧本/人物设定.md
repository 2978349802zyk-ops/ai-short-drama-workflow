|---|---|
| **姓名** | 林晚 |

| **身份** | 独居回声公寓 302 的上班族 |

## 人物二：影（门内镜像体）

| 项 | 内容 |
|---|---|
| **姓名** | 无（剧中不称呼，剧本标注为"影"） |
| **年龄** | 与林晚相同 |
| **身份** | 302 门后的存在，与林晚完全同貌 |
| **性格** | 不说话时像静止的人偶，只有眼睫会动；说话时用林晚的原声，延迟两秒 |
| **背景** | 未知。它不是从外面进来的——林晚一直在门外 |
| **标志性动作** | 所有动作与林晚**完全同步**，分毫不差 |

### 外观锁（提示词逐字复制）

```
外貌与林晚完全一致，齐肩黑茶色碎发，鹅蛋脸，穿藏黑色加绒连帽睡裙，光脚无鞋，脖子上挂着一枚黑铁材质的小月牙吊坠，虹膜呈浅灰色
```

---

## 两人区分表（观众靠这个认人）

| 项 | 林晚 | 影 |
|---|---|---|
| 睡裙 | 米白色加绒连帽 | **藏黑色加绒连帽** |
| 鞋 | 浅灰兔子造型棉拖 | **光脚无鞋** |
| 吊坠 | 银质小月牙 | **黑铁小月牙** |
| 虹膜 | 正常深色 | **浅灰色** |
| 手持 | 半满玻璃杯 | **空手** |
| 声音 | 正常 | 与林晚**完全相同的音色**，延迟两秒 |

**只靠睡裙颜色和鞋就能区分——这是刻意的设计，防止 AI 出图时两人糊成一个。**
