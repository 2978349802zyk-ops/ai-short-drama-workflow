# 《回声公寓》EP01 精剪 v4 剪辑决策

**版本**：v4 精剪完整版（首次带完整音轨）

**输出路径**：`07_剪辑工程/EP01_精剪_v4.mp4`

## 一、整体改动概述

相对 v3 粗剪的主要改动：

| 改动维度 | v3 粗剪 | v4 精剪 |
|---------|---------|---------|
| 转场方式 | 硬切为主 + 微闪帧 | 软切（crossfade）为主 + 闪帧前后叠化 |
| 衔接流畅度 | 冲击力强、跳转硬 | 丝滑衔接 + 动作匹配 + 运动方向统一 |
| 开场音效 | 无 | 完整蒙太奇音效设计（6 秒 6 段） |
| 音轨 | 无音轨 | 三层音轨（配音 + 音效 + BGM） |
| 调色 | 无统一调色 | 全片悬疑色调 + 冷暖分区 |
| 稳定/裁剪 | 无 | 轻微稳定 + 安全框裁剪 |
| 结尾 | 简单定格 | 定格 + 缓慢推近 + 渐黑 |

## 三、调色参数

### 全片基础调色（悬疑色调）
```
eq=brightness=-0.05:contrast=1.08:saturation=0.85
colorbalance=rs=-0.03:gs=-0.02:bs=0.05   // 暗部偏冷蓝
```

### 分区调色
| 场景类型 | 亮度 | 对比度 | 饱和度 | 色温 | 适用镜头 |
|---------|------|--------|--------|------|---------|
| 走廊冷调 | -5% | +8% | -15% | 偏冷（蓝+5%） | S02, S03, S04, S07, S08, S11, S14, S15 |
| 门内暖调 | -3% | +10% | -10% | 偏暖（黄+8%） | S05, S06, S09, S12, S13 |
| 蒙太奇 | 渐变 | +12% | -20% | 偏冷 | S01 A1-A5 |

**设计思路**：冷暖对比强化「两个世界」的对立——走廊是林晚的现实（冷），门内是影的存在（暖）。

### 层 3：BGM（悬疑氛围垫）

**合成方式**：ffmpeg 合成（双低频 drone + 粉噪纹理 + 脉冲层）
**基频**：45Hz + 67Hz 双音叠加，低频脉冲 55Hz
**纹理**：粉噪 + 低通 + tremolo，模拟空气感

#### BGM 起伏曲线

| 15.6–25.5s | S05 奇观1 | 0.40 | 第一波张力 |

| 42.0–52.0s | S09 奇观2 | 0.45 | 第二波张力峰值 |

### 母带处理
- 三层混音 → 压缩器（threshold -18dB, ratio 3:1）→ 限幅器（-1.5dBTP）→ loudnorm（I=-18, TP=-1.5, LRA=11）

## 五、转场设计细节

### 1. Crossfade 叠化
- 叙事段 0.20–0.25s：自然流畅，不突兀
- 情绪转换 0.25–0.30s：给观众情绪缓冲
- 闪帧前后 0.1s：柔化硬冲击，保留冲击力但不跳脱

### 2. 动作匹配转场
- **S07→S08**：S07 结尾手抬到胸前高度 → S08 开头手在同高度伸出手机，两帧对齐
- **S11→S12**：拍门最后一下结束帧 → 门开第 1 帧，中间零空隙
- **S14→S15a**：转身动态最大帧 → S15a 入画从同一运动方向接续

### 3. 运动方向匹配
- S07（人物向左退）→ S08（人物从左入画）：保持左向运动惯性
- S05（推镜）→ S06（推镜）：digital zoom 模拟推镜延续
- S13（推镜）→ S14（拉镜反向）：制造反差冲击

### 4. 颜色过渡
- 冷→暖（走廊→门内）：亮度渐变 0.2s，避免跳闪
- 暖→冷（门内→走廊）：同样亮度渐变过渡

---

## 六、画面稳定与裁剪

- 所有镜头应用 1.5% 安全框裁剪（crop + zoom），消除边缘 AI 变形
- S01/S05/S09/S13 等奇观镜头应用轻微 deshake 处理（AI 生成抖动）
- 边缘质量差的镜头额外 0.5% zoom

---

## 七、结尾处理

1. S15a 中景 4.8s（拉长悬念）
2. S15b 定格 2.0s（抽帧 + zoompan 1.0→1.04 缓慢推近）
3. 最后 1.2s 渐黑（st=0.8s, d=1.2s）
4. 黑屏留 0s（定格结束即结束，黑屏已在渐黑中完成）
5. 音轨：定格处重低音冲击 + 耳鸣声残留，BGM 几乎消失
