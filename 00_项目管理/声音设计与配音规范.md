# 声音设计与配音规范

> 用途：补声音设计层、配音情绪、降噪三件事。对应缺口 7（声音设计）、8（配音表演）、9（嘶声）。

## 一、声音设计层（现在只有配音，缺这两层）

### BGM
- 恐怖悬疑只用低频氛围垫：单音持续、缓慢起伏，不许有旋律抢戏
- 钩子镜和反转镜前 0.5 秒抽掉 BGM（静默比音乐更吓人），反转落点再砸回来
- BGM 音量比配音低 12–15 dB，只做底不做主
- 版权：只用无版权/自制氛围音，不许直接拿平台热门曲（限流风险）

| 音效 | 用途 | 备注 |
|---|---|---|
| 门轴吱呀 | 门自开 | 慢速版，3 秒拉长 |
| 门缝风声 | 门缝特写 | 低频，贴耳朵 |

## 二、配音情绪分段（补缺口 8）

### 情绪标注表（写进 `剧本.json` 每句台词）
每句台词新增字段 `emotion`，取值只能是：

| emotion | 语速 | 停顿 | 适用 |
|---|---|---|---|
| `平静` | 正常 | 正常 | 日常交代、旁白 |
| `紧张` | 略快 | 句内短停 | 发现异常、凑近确认 |
| `惊恐` | 快、气声 | 词间断开 | 被抓、看见门里的人 |
| `压低` | 慢 | 长停顿 | 自言自语、门后声音 |

### 切句规则
1. 一句台词只许一个情绪，情绪变了就切句
2. 惊恐句不许超过 8 个字，长了拆开
3. 每句生成后仍按原规则裁静音 + atempo 贴时长
4. 数字读法铁律不变：字幕阿拉伯数字，TTS 文本汉字（302 → 三零二）

### TTS 参数按情绪微调（在原固定参数上动）
- `平静`：原参数（温度 0.55 / top_p 0.85 / speed 0.95 / seed 42）
- `紧张`：speed 1.0，温度 0.6
- `惊恐`：speed 1.05，温度 0.65，生成后加轻微气声处理（高频提升 2 dB）
- `压低`：speed 0.9，音量 −3 dB，低频提升 2 dB

## 三、降噪（补缺口 9：TTS 自带 4–8 kHz 嘶声）

### 现状
qwen3-tts 输出自带宽带嘶声，RNNoise 只能降 1–2 dB 无效，现用高频滤波+afftdn+低切压制，未根治。

### 方案（按顺序试）
1. **DeepFilterNet**（开源，专治宽带噪声）：对原始 wav 母版跑一遍再进混音链。预期比 RNNoise 好得多，适合这种稳定嘶声。
2. **换 TTS 模型**：CosyVoice / IndexTTS / GPT-SoVITS（均为开源中文方案），嘶声问题小，还能克隆固定音色。换之前先用同一句台词 A/B 听一遍。
3. **频谱门限**：嘶声是稳态的，可在 4–8 kHz 做自适应门限，台词间隙自动压低，台词段不动。

### 纪律（不变）
- 降噪和响度二次处理都从原始 wav 母版重做，不许拿已归一化的成片再压
- 混音链顺序不变：降噪 → compand → alimiter → 响度归一 −16±2 LUFS
- 换任何一步，先用 EP01 现有配音跑一遍对比，听过再定
