## T2 关键帧回填 → `muse_shoot.py`

依据：《成本路线与关键帧回填规范》第二节。

1. 每镜验收通过后，自动抽最后一帧存 `06_视频素材\回填帧\回填帧_S<N>.png`（宽度 ≥600px，不足则跳过并记日志）
2. 下一镜同场景时，参考图 = 人设包两组图 + 回填帧，提示词加固定句：`起始画面与回填帧一致，人物位置、服装、光线不要变，只动镜头和动作。`
3. 换场景不回填；一镜失败重生时回填帧不变
4. `gen_mode` 分流：`video` 走生成，`still` 只出图，`reuse` 跳过生成直接引用旧镜

验收：跑一集 6–8 镜，报每镜用的参考图清单，确认连续镜带了回填帧、换场景没带。

## T3 配音情绪 → 配音生成脚本

依据：《声音设计与配音规范》第二节。

1. `剧本.json` 每句台词新增 `emotion` 字段，枚举：平静/紧张/惊恐/压低，一句一情绪，情绪变就切句
2. TTS 参数按情绪表微调（平静用原参数；紧张 speed 1.0 温度 0.6；惊恐 speed 1.05 温度 0.65；压低 speed 0.9 音量 −3dB）
3. 数字读法铁律不变（字幕阿拉伯数字，TTS 文本汉字）

验收：同一句台词四种情绪各生成一条，报参数和时长，人工听过再定。

## T4 跨集连续性 → `drama_from_theme.py`

依据：《跨集连续性表与人脸自动比对》第一节。

1. 在 `00_项目管理\连续性表.md` 建表（模板已在规范里，EP01 两行示例已填）
2. 新一集生成时，把上一集的表内容拼进剧本 prompt，约束服装/道具/伤情/场景状态不许穿帮
3. 每集拍完把本集状态追加一行，悬念账只许往下带

验收：生成 EP02 剧本时报 prompt 里带了哪几行连续性信息。

## T5 降噪试跑 → 音频后期脚本

依据：《声音设计与配音规范》第三节。

1. 用 EP01 现有配音原始 wav 母版试 DeepFilterNet，过一遍和现行链（afftdn+低切）对比
2. 报告：4–8 kHz 嘶声电平变化、听感结论（人工听）
3. 只试跑，不改正式混音链，结论出来再定换不换

## T6 人脸自动比对 → 新建 `_工具\_face_check.py`

依据：《跨集连续性表与人脸自动比对》第二节。不急，T2–T5 做完再说。

1. InsightFace 提取每镜 3 帧人脸特征，和定妆头图比相似度
2. ≥0.6 通过，0.45–0.6 人眼复核，<0.45 判作废，侧脸/遮挡帧跳过
3. 结果写 `生产记录.jsonl`，人眼验收 C 不取消
