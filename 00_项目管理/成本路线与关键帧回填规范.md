# 成本路线与关键帧回填规范

> 用途：砍生成成本 + 压连续镜头漂移。对应缺口 4（成本）、5（一致性升级的回填部分；头身分拆见《头身分拆人设包》）。

---

## 一、成本路线：混合生成，不再每镜都走视频生成

### 分镜时先给每镜打标签
`剧本.json` 每镜新增字段 `gen_mode`，三选一：

| 模式 | 用什么 | 适合 | 成本 |
|---|---|---|---|
| `video` | Muse 视频生成（带参考图） | 人物动作、反转、钩子镜 | 最高 |
| `still` | 静帧图 + 推拉/摇移（Ken Burns） | 空镜、过渡、环境交代、定格悬停 | 只出图，省视频额度 |
| `reuse` | 复用已生成镜头（换裁切/调色/时长） | 同场景重复出现、闪回、结尾黑场 | 零生成 |

### 分配规则
1. `钩子` 和 `反转` 功能的镜：必须 `video`
2. `推进` 镜：优先 `still`，人物有明显动作才 `video`
3. `断点` 镜：`still` 悬停或 `reuse` 黑场，不许 `video` 浪费额度
4. 同一场景第 2 次出现：优先 `reuse`
5. 目标：一集 28 镜里 `video` 不超过 14 镜，总生成量砍一半

### 静帧推拉参数（写进剪辑脚本，不手调）
- 推近：1.0 → 1.08 倍，匀速，2–3 秒
- 拉远：1.08 → 1.0 倍
- 横移：水平位移 ≤ 画面宽 5%
- 悬停定格：不动，只靠声音压（配环境音/心跳）

## 二、关键帧回填（连续镜头防漂移）

### 做法
1. 第 N 镜成片验收通过后，抽最后一帧（或最清晰一帧）存为 `回填帧_S<N>.png`
2. 第 N+1 镜生成时，参考图 = 人设包两组图 + `回填帧_S<N>.png`（三图一起喂）
3. 提示词加一句：`起始画面与回填帧一致，人物位置、服装、光线不要变，只动镜头和动作。`

### 规则
- 只回填同一场景连续镜头，换场景不回填
- 回填帧必须来自已验收的成片，不许用未验收的
- 回填帧宽度 ≥ 600px，和参考图合规门槛一致
- 一镜失败重生时，回填帧不变，只改提示词或换参考图（沿用原失败处理规则）

### 效果边界（实话）
回填压的是姿态和空间漂移，脸还是靠头身分拆锁。两者一起用，漂移压到最低，但不能保证每帧像素级一致，验收三道门不能省。

## 三、和现有流程的接法

1. `drama_from_theme.py` 生成分镜时带上 `gen_mode` 字段，按第一节规则分配
2. `muse_shoot.py` 按 `gen_mode` 分流：`video` 走生成，`still` 只出图，`reuse` 跳过
3. 验收通过后自动抽回填帧，存进 `06_视频素材\回填帧\`
4. 每集生成前先报一遍成本预估：`video` 几镜、`still` 几镜、`reuse` 几镜，确认再开跑
